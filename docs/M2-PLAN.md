# M2 文件夹导入

> 目标：拖一个文件夹 → 目录层级原样还原成文档树；非 md、空目录、资源目录明确跳过。
> 前置：`docs/DESIGN.md` v0.2（§5.2 层级映射 / §5.4 内核补建父级 / §7.4 父文档复用 / §9 异常矩阵）、M1 已完成。

---

## 1. 范围

| 做 | 不做（留给后面） |
|---|---|
| 递归读目录，层级原样还原 | 压缩包（M3） |
| 非 md / 系统垃圾 / 资源目录跳过 | 图片上传（M4） |
| 空目录跳过（不建空文档） | 追加 / 跳过 / 覆盖策略（M4） |
| 同名父文档复用、子文件加 `(2)` | 取消导入（M3） |
| 批量导入时的进度卡片 | 撤销（M4） |

## 2. 两个已定的取舍（2026-10-24）

1. **空目录跳过不建**。DESIGN §5.4 曾提出「空壳目录显式建父文档」，§9 又说「空文件夹不建文档」——两处冲突，取后者：树里不出现只有标题的空文档。
2. **批量先给反馈**。松手后立刻出「正在导入 N 篇」卡片（带 `已导入 / 总数` 和当前文件名），跑完在同一位置换成结果卡片。M3 再补取消与单篇耗时。

## 4. 关键行为

- **层级**：`/投放目标/项目A/spec/c`，父级由 `createDocWithMd` 补建（M0 已验证，不逐层查建）。
- **目录不改名**：同名目录一律视为「合并进已有父文档」（§7.4）；只有文件重名才加 ` (2)`。
- **整棵跳过**：`.` 开头的目录（`.git` / `.obsidian` …）、`node_modules`、`__MACOSX`；只写日志，不进卡片。
- **资源目录**：`assets` / `attachments` / `img` / `images` / `static` 整棵跳过，按文件数在卡片汇总一行（M4 才随正文上传）。
- **系统垃圾**：`Thumbs.db` / `desktop.ini` / `.DS_Store` / `._*` 直接忽略，不计数。
- **上限**：单次 2000 篇、层级 20 层、路径 259 字符；超限项进「跳过」并给原因。
- **空目录**：整棵子树没有 md 才算空，只报最上面那一层，不重复报嵌套空目录。

## 6. 需要人工验收

1. 拖 `项目A/`（含 `a.md`、`b.md`、`spec/c.md`、一个空目录、一张图）→ 树里 `项目A → a、b、spec → c`，空目录和图片不建文档。
2. 拖到某个文档上 → `项目A` 整个挂在它下面。
3. 再拖一次同一个文件夹 → 父文档还是那一个，文件变 `a (2)`。
4. 拖一个只有图片的文件夹 → 卡片「文件夹里没有 md 文件」。
5. 拖 100 篇以上的文件夹 → 立刻出「正在导入 N 篇」，数字递增、进度条走，结束后原地变结果。
6. 拖含 `.obsidian/` 的笔记库 → 隐藏目录不导入（日志里能看到被忽略的目录名）。

## 7. 已知缺口

- 资源目录里的图片**不会**跟着 md 上传，正文里的 `![](img/a.png)` 目前仍是死链——M4 处理。
- 单次 2000 篇是硬上限，超出的部分只给一条「文件过多」提示，不做分批续传。
- 进度卡片没有取消按钮（M3），点了关闭也只能等它跑完。
